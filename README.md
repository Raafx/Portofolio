# RAAFX Portfolio
React + Vite + Tailwind CSS v4 + Lucide.

    npm install
    npm run dev      # development
    npm run build    # production build

Edit content in `src/data/` (projects, certificates, techStack). Put images in `public/assets/{projects,certificates,images}` and the CV at `public/assets/cv.pdf`. Replace the ghost by swapping `<PixelGhost />` in `Hero.jsx` with an `<img>`.
